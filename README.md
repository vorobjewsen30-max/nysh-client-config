# Nysh Client — публичная конфигурация

Редактируйте `config.json` через GitHub → Edit → Commit changes. Данные публичны: не размещайте здесь пароли, токены или адреса закрытых сервисов.

`servers` — список рекомендованных серверов. У каждого постоянный уникальный `id`, `name`, `address`, `description`, `featured`. Nysh SMP поставляется по умолчанию. Личные записи игроков сохраняются отдельно.
`news` — новости (`id`, `title`, `text`, `url`). `links` — сообщества. `update` — номер версии, список изменений и HTTPS-ссылка на выпуск.

Лаунчер обновляет конфигурацию при запуске. При сбое сети использует последнюю проверенную копию. Ресурспак Nysh SMP выдаёт сервер, лаунчер его не устанавливает.
